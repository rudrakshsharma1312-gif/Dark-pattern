The Four Deceptive Patterns We Target

Online retailers routinely exploit cognitive biases to rush decisions and inflate basket sizes. DarkGuard AI rigorously checks for evidence behind each claim.

DP-1 Rule Verification

Fake Urgency & Scarcity

Artificial countdown timers and manufactured scarcity claims (e.g., "Only 2 left!") designed to induce panic and force an impulsive checkout before the customer can research alternatives.

Evidence Verification: Observes countdown timers over a 10-second window. If timer digits stay frozen or claim deadlines without state change, DarkGuard flags the element with temporal proof.
DP-2 Arithmetic Proof

Misleading Discount Calculations

Exaggerated percentage-off claims that do not mathematically correspond to the difference between reference price (MSRP/Was) and current sale price.

Evidence Verification: Extracts reference and sale prices, calculates ((Was - Now) / Was) * 100, and flags any discrepancy exceeding 5 percentage points (e.g., claiming 70% off when it is actually 50%).
DP-3 Rule + ML Phrasing

Confirm Shaming Phrasing

Guilt-inducing, manipulative decline button copy that shames or patronizes shoppers for opting out of discounts, insurance, or mailing lists (e.g., "No thanks, I prefer paying full price").

Evidence Verification: Combines an exact 40+ curated shaming lexicon with an on-device TF-IDF text classifier to detect guilt-inducing opt-out language near primary call-to-action buttons.
DP-4 DOM State Audit

Pre-Selected Extras & Add-ons

Optional extras—such as extended warranties, courier insurance, damage protection, or recurring subscriptions—that are pre-checked by default near the Add to Cart button without explicit buyer consent.

Evidence Verification: Audits the DOM for checkbox inputs with checked="true" located in purchase action areas containing add-on keywords (warranty, insurance, protection plan, subscription).
Simple Workflow

How DarkGuard AI Works in 3 Steps

Zero complex configuration. Seamlessly integrates into your shopping journey without slowing down your browser.

1

Open Shopping Page

Navigate to any e-commerce product page, deal portal, or explore our built-in 14-scenario evaluation test bed.

2

Scan with DarkGuard AI

Open the extension popup and click Scan this page. DarkGuard audits visible pricing, timers, decline buttons, and checkboxes in milliseconds.

3

Review & Restore

Inspect findings, highlight suspicious elements, view the 0–100 risk score, or toggle Ethical View with a 1-click Show Original guarantee.

Core Capabilities

Engineered for Honest Consumer Defense

Built on principles of evidence-based proof, consumer safety, and absolute privacy.

Evidence-Based Findings

Every detection presents concrete proof: exact discount arithmetic, frozen timer timestamps, or matched manipulative decline phrases.

Unified 0–100 Risk Score

Transparent severity weighting translates multiple pattern detections into an intuitive risk gauge (Low, Moderate, High, Very high).

Visual Highlighting

Clicking any finding smoothly scrolls the viewport to the deceptive element and highlights it with an animated, non-destructive pulse overlay.

Ethical View & Show Original

Adds small explanatory notes and a top banner to contextualize deceptive design. Never alters prices, buttons, or checkboxes, with full 1-click restore.

100% On-Device Privacy

All rule matching and text classification run entirely inside your browser. No passwords, card data, or browsing history ever leave your device.

Hybrid Fusion Architecture

Combines strict deterministic DOM heuristics with a fast TF-IDF logistic classifier. Gracefully falls back to rules if the ML model is disabled.

Quick Start

Install in 2 Minutes (Judge Quick-Start)

Install DarkGuard AI into Google Chrome, Brave, or Microsoft Edge using standard Developer Mode.

Download Extension Package (.zip)
Single-source verified: identical to repository extension-dist/ • 100% on-device
1

Get the extension files (2 options)

Option A (Website): Download darkguard-extension.zip and extract all files to a folder.
Option B (Git Clone): Clone this repository and use the pre-built extension-dist/ directory directly. No npm install or build required! (Do NOT select the repository root).

2

Open Extensions Management in your browser

Navigate to chrome://extensions in Chrome/Brave (or edge://extensions in Edge).

3

Enable Developer Mode & Load Unpacked

Toggle ON Developer mode (top-right corner). Click Load unpacked (top-left) and select the extracted folder (or the extension-dist/ folder from your clone).

4

Pin and Scan

Pin the DarkGuard AI shield icon to your toolbar. Open test-site/planted-combined-01.html, open the extension popup, and click Scan this page.
